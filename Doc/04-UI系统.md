## 整体定位

YFramework 的 UI 层提供：

- 一个层级化多窗口管理框架
- 一批自定义 UI 组件
- 一批布局和交互辅助脚本
- 一些方便在编辑器里创建 UI 控件的菜单项

## 1. GameUIKit —— 层级化 UI 管理框架

文件：

- `Assets/YFramework/UI/Runtime/GameUIKit.cs`
- `Assets/YFramework/UI/Runtime/UIKitRuntime.cs`

GameUIKit 是一个轻量级、层级化的 UI 窗口管理框架。它不依赖闭源路由表或资源异步加载系统，核心仅由**静态 API 门面**和**实例级运行时**两层组成。

### 1.1 核心概念

**UILayer** — 五层渲染优先级：

```
Bg(0) → Player(1) → Normal(2) → Effect(3) → Highest(4)
```

同一层内的 UI 按打开顺序堆叠，后打开的在上方。

**IUIRoot** — 桥接接口，连接静态 API 与具体运行时实现：

```csharp
public interface IUIRoot
{
    GameObject OpenUI(UILayer layer, GameObject uiObject, object userData = null);
    bool CloseUI(GameObject uiObject);
    bool CloseTopUI(UILayer layer);
    void CloseLayerUI(UILayer layer);
    void CloseAllUI();
    bool IsUIOpen(GameObject uiObject);
    bool ReleaseUI(GameObject uiObject);
    GameObject GetOpenedUI(GameObject uiObject);
}
```

**IUIWindow** — UI 窗口生命周期回调接口：

```csharp
public interface IUIWindow
{
    void OnUIOpen(UILayer layer, object userData);
    void OnUIClose();
}
```

**UIWindowBase** — 便捷基类，继承 `MonoBehaviour`，提供 `CloseSelf()` 快捷方法：

```csharp
public class UIWindowBase : MonoBehaviour, IUIWindow
{
    public virtual void OnUIOpen(UILayer layer, object userData) { }
    public virtual void OnUIClose() { }
    public void CloseSelf() { GameUIKit.Close(gameObject); }
}
```

### 1.2 GameUIKit 静态 API

GameUIKit 是所有业务代码的**唯一入口**。所有操作通过静态方法完成：

| 方法 | 说明 |
|---|---|
| `RegisterRoot(IUIRoot)` | 注册运行时根节点 |
| `UnregisterRoot(IUIRoot)` | 注销运行时根节点 |
| `HasRoot` | 是否已注册根节点（bool 属性） |
| `Open(UILayer, GameObject, object)` | 打开 UI，可传入 userData |
| `Close(GameObject)` | 关闭指定 UI |
| `CloseTop(UILayer)` | 关闭指定层最顶部的 UI |
| `CloseLayer(UILayer)` | 关闭指定层的所有 UI |
| `CloseAll()` | 关闭所有层的所有 UI |
| `IsOpen(GameObject)` | 查询 UI 是否处于打开状态 |
| `Release(GameObject)` | 释放 UI（关闭 + 销毁运行时实例） |
| `GetOpened(GameObject)` | 获取已打开的 UI 实例（通过预制体源查询） |

### 1.3 基础用法

**初始化** —— 创建 UIKitRuntime 并注册：

```csharp
// 在某个 MonoBehaviour 中
private UIKitRuntime m_uiRuntime;

void Awake()
{
    m_uiRuntime = new UIKitRuntime(this);

    // 构造回调
    var callbacks = new UIRuntimeCallbacks
    {
        NotifyOpen = GameUIKit.NotifyOpen,
        NotifyClose = GameUIKit.NotifyClose,
        // 可选：动画回调（不接线则无动画）
        // NotifyOpenAsync = GameUIKit.NotifyOpenAsync,
        // NotifyCloseAsync = GameUIKit.NotifyCloseAsync,
    };

    // 实现 IUIRoot 并注册
    // GameUIKit.RegisterRoot(yourRootImpl);
}
```

**打开 UI**：

```csharp
// 直接传入预制体，框架自动 Instantiate
GameObject instance = GameUIKit.Open(UILayer.Normal, myPrefab, userData);
```

**关闭 UI**：

```csharp
// 通过实例关闭
GameUIKit.Close(instance);

// 或通过 UIWindowBase 子类内调用
CloseSelf();

// 关闭 Normal 层最顶部 UI
GameUIKit.CloseTop(UILayer.Normal);

// 关闭 Normal 层所有 UI
GameUIKit.CloseLayer(UILayer.Normal);
```

**编写 UI 窗口**：

```csharp
public class MyDialog : UIWindowBase
{
    public override void OnUIOpen(UILayer layer, object userData)
    {
        // 初始化 UI，userData 是 Open 时传入的附加数据
    }

    public override void OnUIClose()
    {
        // 清理资源
    }
}
```

### 1.4 场景 UI 注册

对于已经放置在场景中、不需要实例化的 UI（如 HUD、常驻面板），使用 `RegisterSceneUI`：

```csharp
var layerRoots = new List<UILayerRoot>
{
    new UILayerRoot((int)UILayer.Normal, normalLayerTransform),
    new UILayerRoot((int)UILayer.Highest, topLayerTransform),
};

m_uiRuntime.RegisterSceneUI(layerRoots, callbacks);
```

场景 UI 特点：
- 不会被 Instantiate，直接使用场景中的 GameObject
- `ShouldDeferSceneObject` 回调可让某些场景 UI 初始化为关闭状态
- 调用 `RegisterSceneUI` 会自动清理之前所有已打开的运行时 UI

### 1.5 默认点击事件

GameUIKit 内置了全局点击音效/反馈机制：

```csharp
// 监听全局点击
GameUIKit.DefaultClick += OnAnyButtonClicked;

void OnAnyButtonClicked()
{
    // 播放点击音效等
}
```

框架在 `NotifyOpen` 时自动为 UI 下所有 `Button` 绑定此事件，在 `NotifyClose` 时自动解绑。

### 1.6 动画支持（opt-in）

动画通过 `UIRuntimeCallbacks` 的可选字段注入，**默认关闭**：

```csharp
var callbacks = new UIRuntimeCallbacks
{
    NotifyOpen = GameUIKit.NotifyOpen,
    NotifyClose = GameUIKit.NotifyClose,

    // 接线后才启用协程动画
    NotifyOpenAsync = MyOpenAnimation,
    NotifyCloseAsync = MyCloseAnimation,
};

// 打开动画：UI 已激活后播放（适合淡入效果）
static IEnumerator MyOpenAnimation(GameObject ui, int layer, object userData)
{
    var canvasGroup = ui.GetComponent<CanvasGroup>();
    canvasGroup.alpha = 0f;
    float t = 0f;
    while (t < 0.3f)
    {
        t += Time.deltaTime;
        canvasGroup.alpha = t / 0.3f;
        yield return null;
    }
}

// 关闭动画：播放完成后才失活（适合淡出效果）
static IEnumerator MyCloseAnimation(GameObject ui)
{
    var canvasGroup = ui.GetComponent<CanvasGroup>();
    float t = 0f;
    while (t < 0.3f)
    {
        t += Time.deltaTime;
        canvasGroup.alpha = 1f - t / 0.3f;
        yield return null;
    }
}
```

动画时序：
- **Open**：激活 → `OnUIOpen`（同步）→ `NotifyOpenAsync` 协程（淡入）
- **Close**：`NotifyCloseAsync` 协程（淡出）→ `OnUIClose`（同步）→ 失活

### 1.7 UIKitRuntime —— 运行时实现

`UIKitRuntime` 是 `IUIRoot` 的具体实现，负责：

- 管理 UI 记录（预制体源 ↔ 运行实例的映射）
- 区分场景对象与预制体：场景对象直接使用，预制体自动 Instantiate
- 按层维护打开顺序，支持 `CloseTop`
- 场景 UI 注册与运行时 UI 清理

```csharp
public sealed class UIKitRuntime
{
    public UIKitRuntime(MonoBehaviour owner);    // owner 用于跑协程

    // 核心操作，callbacks 中注入 GameUIKit 的静态通知方法
    public GameObject Open(int layer, Transform layerRoot, GameObject uiObject,
                           object userData, UIRuntimeCallbacks callbacks);
    public bool Close(GameObject uiObject, UIRuntimeCallbacks callbacks);
    public bool CloseTop(int layer, UIRuntimeCallbacks callbacks);
    public void CloseLayer(int layer, UIRuntimeCallbacks callbacks);
    public bool IsOpen(GameObject uiObject);
    public bool Release(GameObject uiObject, UIRuntimeCallbacks callbacks);
    public GameObject GetOpened(GameObject uiObject);
    public void RegisterSceneUI(IEnumerable<UILayerRoot> layerRoots,
                                UIRuntimeCallbacks callbacks);
}
```

### 1.8 设计边界

GameUIKit 是轻量级管理框架，**不包含**：
- 面板路由 / URL 导航
- 异步资源加载（Addressables / AssetBundle）
- 窗口配置表
- 模态遮罩自动管理
- 返回栈（业务层需要可基于 CloseTop 自行封装）

这些按业务需求在 GameUIKit 之上继续封装。

## 2. UI 自定义图形组件

### `CircleImage`

文件：

- `Assets/YFramework/UI/Runtime/Custom/Image/CircleImage.cs`

定位：

- 继承 `UnityEngine.UI.Image`
- 通过重写 `OnPopulateMesh` 动态生成圆形网格
- 同时重写 `IsRaycastLocationValid`，实现圆形区域射线检测

功能特征：

- 用 `segments` 控制圆的分段数
- 通过顶点计算生成圆面
- 维护 `_vertexPos` 供点击命中判断使用

典型用途：

- 圆形头像
- 圆形进度视觉
- 非矩形点击区域

### `PolygonColliderImage`

文件：

- `Assets/YFramework/UI/Runtime/Custom/Image/PolygonColliderImage.cs`

定位：

- 继承 `Image`
- 依赖同物体上的 `PolygonCollider2D`
- 用碰撞体形状决定 UI 点击有效区域

适合：

- 不规则图片点击
- 比圆形更复杂的命中区域

## 3. 自适应与布局辅助

### `SlideScrollHorizontal`

文件：

- `Assets/YFramework/UI/Runtime/Adaptive/SlideScrollHorizontal.cs`

定位：

- 一个横向分页滚动辅助脚本

主要能力：

- 记录当前页 `currentIndex`
- 通过拖拽左右切页
- 支持上一页 / 下一页按钮
- 支持页码文本
- 支持 `JumpToPage(int)`

依赖：

- `ScrollRect`
- `GridLayoutGroup`

适用场景：

- 横向卡片页
- 简单轮播页
- 分页道具列表

### `RawImageAdaptivityLayout`

文件：

- `Assets/YFramework/UI/Layout/RawImageAdaptivityLayout.cs`

定位：

- 让 `RawImage` 在指定显示区域内按比例适配

关键特征：

- `[ExecuteAlways]`
- `Update()` 中持续执行适配
- 实际调用的是 `UIExtension.AdaptivitySize(...)`

用途：

- 编辑态 / 运行态都保持图片适配

### `UIExtension`

文件：

- `Assets/YFramework/UI/Extension/UIExtension.cs`

提供的高频能力包括：

- `ScrollRect.UpdateContentLength(...)`
- `RectTransform.AdaptivitySize(...)`
- `HorizontalLayoutGroup.SetCenterSize()`

这些方法主要服务于：

- Grid + ScrollRect 动态内容尺寸计算
- 图片按区域缩放
- 水平布局的内容居中

## 4. 指针事件辅助

### `PEListener`

文件：

- `Assets/YFramework/UI/Runtime/EventSystem/PEListener.cs`

它实现了：

- `IPointerClickHandler`
- `IPointerDownHandler`
- `IPointerUpHandler`
- `IDragHandler`

作用是把 Unity 事件接口转成可直接赋值的委托字段：

- `onClick`
- `onClickDown`
- `onClickUp`
- `onDrag`

适合：

- 临时 UI 交互接线
- 不想额外写一个专门组件类时的快速交互代理

## 6. UI 层与 AutoBind 的关系

YFramework 的 UI 代码与 AutoBind 契合。
这是因为：

- `AutoBindRules` 内置了大量 UI 前缀
- 测试样例里也以 UI 控件绑定为主

所以当你看到下面这些节点名时，通常意味着它们预期走 AutoBind：

- `BtnClose`
- `TxtTitle`
- `ImgAvatar`
- `TogMusic`
- `RectContent`

## 7. 当前边界与不足

### 1. GameUIKit 是轻量级框架，不含路由和资源加载

更高层的面板路由、异步资源加载需业务侧自行封装。

### 2. 部分脚本是强场景化组件

例如 `SlideScrollHorizontal` 假设了较具体的 `ScrollRect + GridLayoutGroup + 页码按钮` 结构。

### 4. 目录里存在非脚本元数据痕迹

`Assets/YFramework/UI/Runtime/Adaptive/.idea` 这类目录不属于运行时设计的一部分，阅读时可以忽略。

## AI 修改建议

如果你要扩展 UI，建议先判断是哪一类需求：

- 面板显示与切换：先看 `GameUIKit` / `UIKitRuntime`
- 非矩形点击：先看 `CircleImage` / `PolygonColliderImage`
- 内容区尺寸适配：先看 `UIExtension`
- 分页滚动：先看 `SlideScrollHorizontal`
- 快速指针事件：先看 `PEListener`

如果需要做更大型的 UI 框架化建设（路由、资源加载、模态管理），建议在 GameUIKit 之上继续封装。
